# Stark VMS — Assignment 1 Flutter client

Run `flutter pub get`, then `flutter run -d chrome --dart-define=VMS_API_URL=http://localhost:9001/api` after starting the backend. See `../README.md` for complete setup and validation instructions.

The generated `.g.dart` files are included. After changing annotated model/API definitions, regenerate with `dart run build_runner build`.
